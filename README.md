# ☕ Chai Theory — Built By Sreenidhi

> **An immersive, high-key daylight digital culinary experience celebrating botanical artisanal chai, filter coffee, and elevated Indian gastronomy.**

![Chai Theory Banner](public/assets/images/img-kulhad-hero.jpg)

---

## 🌟 Overview

**Chai Theory** re-imagines the traditional Indian café experience with state-of-the-art web interaction design. Built around an aesthetic of **high-key daylight warm whites (`#FAFAF8`)**, **curated botanical accents (Saffron, Chili, Cardamom)**, and **fluid scroll-driven physics**, this project elevates everyday street food and artisanal brewing into an interactive digital gallery.

---

## ✨ Key Features & Interactive Moments

### 🍽️ 1. The Grand Thali Deconstructed
* **Pinned Assembly Scrub**: As the user scrolls through the showcase, individual culinary components (crispy rolled *Masala Dosa*, slow-simmered *Drumstick Sambar*, golden *Medu Vadas*, and fresh *Coconut Chutney*) fly in from exploded 3D trajectories and settle seamlessly onto an artisan white ceramic plate.
* **Assembly Integrity HUD**: Real-time progress tracker measuring composition precision.
* **Saffron Pop Labels**: Staggered metadata cards revealing ingredient origins and culinary techniques.

### 🌿 2. Botanical Architecture (Spice Orbit)
* **Gravitational Orbit**: Six whole spices (*Idukki Green Cardamom*, *Ceylon True Cinnamon*, *Star Anise*, *Zanzibar Clove Buds*, *Sun-Dried Ginger*, and *Tellicherry Black Pepper*) orbit a steaming central Kulhad chai cup.
* **Upright Label Counter-Rotation**: Custom trigonometric GSAP timeline ensuring all typography remains perfectly readable and level throughout orbital rotation.

### ☕ 3. The Aeration Meter — Filter Coffee Pull
* Showcasing the 80:20 Arabica-Chicory decoction cooled by meter-high pulls, complete with froth thermodynamics and roasting notes.

### 🥟 4. Street Food Elevated — Exploded Samosa
* Interactive scroll anatomy breaking down hand-rolled ajwain pastry, spiced potato-pea core, and mint-coriander emulsion.

### 🍵 5. Fusion & Textures Gallery
* Dual-stream visual clash comparing Alphonsa Mango Lassi with Ceremonial Grade Uji Matcha.
* Horizontal drag/scroll gallery featuring handcrafted Indian sweets (*Saffron Jalebi*, *Rosewater Gulab Jamun*).

### 📋 6. Reservation Concierge
* Fluid reservation modal with table selection, time slots, and celebratory interactive particle canvas.

## 🛠️ Technology Stack

| Technology | Purpose |
| :--- | :--- |
| **HTML5 & Vanilla CSS3** | Semantic structure, CSS custom properties, glassmorphism, responsive grid layouts |
| **JavaScript (ES6+)** | Component logic, state orchestration, DOM event handling |
| **GSAP 3 + ScrollTrigger** | High-performance pin-scrub animations, timelines, and parabolic trajectories |
| **Lenis Scroll** | Inertial momentum scrolling synced to requestAnimationFrame |
| **Canvas Confetti** | Dynamic celebratory particle effects |
| **Vite** | Blazing-fast development server and optimized production bundler |

## 🚀 Getting Started

### Prerequisites
* [Node.js](https://nodejs.org/) (version 18+ recommended)
* `npm` or `pnpm`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sreenidhi1628/chai-theory.git
   cd chai-theory
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000/`.

4. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled static assets will be output to the `dist/` folder.
